التحقق من مستند

1. إعداد مستودع GitHub

المستودع عام، الفرع main، و GitHub Pages من الجذر. رابط التحقق:

لا ترفع مستندات سرية أو بيانات شخصية إلى مستودع عام. رمز GitHub السري مطلوب فقط عند النشر ولا يُحفظ في الموقع أو المتصفح بواسطة هذا الكود.

2. تجهيز المستند

يوضع QR داخل مساحة الصفحة وقد يغطي جزءاً من المحتوى. اختر زاوية فارغة وراجع المعاينة قبل النشر. لا تستخدم هذه النسخة لتعديل ملفات موقعة رقمياً.

3. المعاينة والنشر

رابط التحقق:

تحميل PDF النهائيفتح PDF للطباعة

استخدم زر الطباعة في عارض PDF أو Ctrl+P. الموقع يسجل الإصدار وليس تأكيد خروج الورقة من الطابعة.
